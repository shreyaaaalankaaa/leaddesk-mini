# AI usage disclosure

I used ChatGPT as a development assistant to pressure-test the application structure, identify edge cases for validation and authentication, and review the clarity of the README and walkthrough outline. I did not use the first generated approach as the final solution: I narrowed the product around the “signal, not CRM clutter” idea, chose the public/admin information hierarchy, changed the data model to preserve a transactional status history, rewrote the interface copy, and manually reviewed the security, responsive behavior, and error states before submission.
